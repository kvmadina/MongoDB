# Mahsulotlar ro'yxati — лаба 6 + ДЗ к 29.09

Express 5 + Mongoose 8 и страница на ванильном JS. Товары лежат в MongoDB Atlas (база `laba`,
коллекция `mahsulotlar`): их можно добавлять, удалять и менять количество — без перезагрузки страницы.

## Установка

```
npm install
```

## Настройка

Скопируйте `.env.example` в `.env` и впишите свою строку подключения из MongoDB Atlas
(Connect → Drivers), не забыв имя базы `laba`:

```
MONGODB_URI=mongodb+srv://ЛОГИН:ПАРОЛЬ@cluster0.xxxxx.mongodb.net/laba
```

`.env` в репозиторий не попадает — он в `.gitignore`.

## Запуск

```
npm start
```

Страница: http://localhost:3000

## Маршруты

| Запрос | Что делает | Ответ |
|---|---|---|
| `GET /mahsulotlar` | список, новые сверху | `200` + массив |
| `POST /mahsulotlar` | добавляет товар | `201` + созданный товар |
| `DELETE /mahsulotlar/:id` | удаляет товар | `200` + удалённый товар |
| `PATCH /mahsulotlar/:id` | меняет поля товара | `200` + уже обновлённый товар |

### Ошибки

| Что прислали | Ответ |
|---|---|
| `_id` корректный, но товара нет (`66f000000000000000000000`) | `404` |
| `_id` кривой (`abc`) | `400` |
| чужая категория (`{ "category": "mashina" }`) или отрицательная цена | `400` |

Почему в одном случае 404, а в другом 400: `abc` вообще не похож на `ObjectId`, Mongoose не может
привести его к типу поля `_id` и бросает `CastError` — виноват сам запрос, это `400`.
А `66f000000000000000000000` по форме правильный: Mongoose идёт в базу, просто не находит документ
и возвращает `null` (не ошибку) — запрос верный, но ресурса нет, это `404`.

## Файлы

- `server.js` — схема и модель товара, четыре маршрута, общая обработка ошибок `sendError`.
- `public/index.html` — разметка и стили страницы.
- `public/app.js` — вся работа с `fetch` и DOM: загрузка списка, форма, кнопки «+1» и «O'chirish».
