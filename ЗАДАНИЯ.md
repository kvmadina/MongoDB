## Подключение (делается один раз)

```bash
npx mongosh "<строка подключения из Atlas>"
```

Устанавливать ничего не надо — `npx` скачает `mongosh` сам. В Atlas: **Connect → Shell**,
там же нажми **Add Current IP Address**, иначе кластер тебя не пустит.

Дальше переключись на свою базу и загрузи набор:

```js
use laba
load("./data.js")
```

> `load()` ищет файл относительно папки, из которой ты запустил `mongosh`. Запускай из папки с `data.js`.

## Задание 3 (10 баллов) — сортировка и лимит

## Задание 4 (10 баллов) — изменение документа

## Задание 5 (10 баллов) — удаление по условию

## Задание 6 (10 баллов) — группировка
